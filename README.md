# ExplainMagic
### Simple description:
A minecraft magical mod. You should correct the basic magic element (BME).<br> 
And try to make some basic physic exciter. Using BME Power to achieve the magic.
### Why I make it?
Most of the magical mod think the magic come from an Item, Entity.<br>
But it's too simple. And some magical explain violate the rule of physics<br>
So, I want a magical system which basic on physics and chemistry.<br>
### Magical power does not arise out of nothing.
Unlimited Use a magic wand? No! If you want to use magical,you need had two thing.<br>
Basic Magic Element(BME) and Magic Script(MS).<br>
BME is power. Using any magic need it. So You should collect it.<br>
MS is the rule to switch the BME to physic power or chemistry material.<br>
### How can I get BME?
Any energy transformation will create a little BME and loss little energy<br>
And loss little is equal generated BME. Of course,The unit of BME is Joule.<br>
If cyclic conversion of energy with a very fast, we can accumulate much BME.<br>
So I defined BME Collect Machine.<br>
### How to make MS?
You can make MS on the MS design table. Notice: Make MS need Basic Magic Item(BMI)<br>
### How to use MS and use magic?
The First is empty magic container, such as Magic wand. And compress BME, some MS.<br>
Using table to craft the magic container. try to left-click it.<br>
